# Support

This project is maintained as an open-source fork by 中揚資訊股份有限公司.

For bugs and documentation issues, use GitHub Issues.

For security issues, do not open a public issue. Use GitHub private vulnerability reporting if enabled, or email `services@joyyoung.com.tw`. See [SECURITY.md](./SECURITY.md).

For general external contact, use `services@joyyoung.com.tw`.

This repository does not provide:

- medical advice;
- emergency support;
- caregiving hotline service;
- diagnosis, triage, treatment, dosage, or urgency judgment;
- production hosting support for third-party deployments.

For production deployment, read [Known Limitations](./docs/governance/KNOWN_LIMITATIONS.md) and [Deploy](./docs/operations/DEPLOY.md) first.

## 繁體中文

本專案由中揚資訊股份有限公司以開源 fork 形式維護。

Bug 與文件問題請使用 GitHub Issues。

資安問題請不要開公開 issue。若 GitHub private vulnerability reporting 已啟用，請優先使用；否則請寄到 `services@joyyoung.com.tw`。請先閱讀 [SECURITY.md](./SECURITY.md)。

一般對外聯絡可使用 `services@joyyoung.com.tw`。

這個 repository 不提供：

- 醫療建議；
- 緊急救援；
- 照護諮詢專線；
- 診斷、分流、治療、劑量或急迫性判斷；
- 第三方 production 部署代管支援。

正式部署前，請先閱讀 [Known Limitations](./docs/governance/KNOWN_LIMITATIONS.md) 與 [Deploy](./docs/operations/DEPLOY.md)。
