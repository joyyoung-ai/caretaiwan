# CareTaiwan 文件導覽

這個目錄放中揚資訊接手後整理的治理、產品、工程、維運、資安與版本文件。根目錄只保留 GitHub 常見入口，例如 README、AGENTS、LICENSE、CONTRIBUTING、SECURITY、SUPPORT、CODE_OF_CONDUCT、CHANGELOG；長文件都放在這裡分類維護。

## Governance

- [governance/PROJECT_VISION.md](./governance/PROJECT_VISION.md)：產品定位、優先順序與不做的事。
- [governance/CONTRIBUTING.md](./governance/CONTRIBUTING.md)：Issue、PR、branch、migration 與 review 規則。
- [governance/DECISIONS.md](./governance/DECISIONS.md)：架構與產品決策紀錄。
- [governance/FORK_NOTICE.md](./governance/FORK_NOTICE.md)：中揚資訊接手背景。
- [governance/KNOWN_LIMITATIONS.md](./governance/KNOWN_LIMITATIONS.md)：目前限制，哪些不是 bug。
- [governance/MAINTAINERS.md](./governance/MAINTAINERS.md)：維護責任與聯絡方式。

## Product

- [product/ROADMAP.md](./product/ROADMAP.md)：產品路線與版本節奏。
- [product/USER_REQUIREMENTS.md](./product/USER_REQUIREMENTS.md)：接手後收到的使用者需求。
