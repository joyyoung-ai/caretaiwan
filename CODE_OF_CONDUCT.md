# Code of Conduct

CareTaiwan welcomes practical, respectful collaboration.

## Expected Behavior

- Keep discussions focused on the issue, code, documentation, or product boundary.
- Be clear about evidence, assumptions, and risks.
- Respect the lived context of foreign family caregivers, elders, and families.
- Do not post personal data, LINE IDs, photos, medical notes, tokens, backup files, or private logs.
- Accept that this project does not provide medical advice or emergency support.

## Unacceptable Behavior

- Harassment, threats, insults, or discriminatory language.
- Publishing private or sensitive information.
- Pressuring maintainers to provide medical, legal, emergency, or production hosting support.
- Repeatedly pushing features that violate the project vision after maintainers have closed the discussion.

## Enforcement

Maintainers may edit, hide, or remove comments, close issues, block users, or reject contributions that violate this code of conduct.

If a problem involves a security vulnerability or private data, do not report it in a public issue. Follow [SECURITY.md](./SECURITY.md).
